# 八爪鱼采集与导出

本项目实际采集工具为八爪鱼，由作者完成。参考报告将平台描述为淘宝，收集的是商品页面相关字段；提供的中间工作簿可检查关键词、商品标题、店铺展示信息、位置、标价和页面付款人数等内容。

## 工作过程

1. 确定与银发消费主题相关的搜索关键词，在八爪鱼中配置商品列表的采集任务。
2. 在样本页面检查字段提取结果，保留标价和付款人数的原始文本，避免先把 `万`、`+` 等信息丢掉。
3. 导出 Excel，并在清洗过程中生成数值列、名称长度、店铺相关指数与标签列。
4. 在本仓库中对齐已有工作簿，生成 `data/source/observations.csv`；由 Python 脚本继续清洗、去重、统计和入库。

原八爪鱼任务配置文件、登录信息和初始完整采集导出未包含在提供材料中，因此不能声称在任意日期或网页版本上可一键重新采集。当前仓库的可复现入口从所提供的处理中间数据开始。未来新增批次应额外保留采集时间、商品 ID、字段原始文本与任务配置版本，便于稳定关联与比较。

## 重新读取原工作簿

如果本地保留五份原工作簿，可以执行：

```powershell
python scripts/prepare_sources.py --source-dir "原工作簿所在文件夹" --output artifacts/source-export
```

脚本只读源文件，逐行核对标题顺序，比较重算特征与最终表，并生成来源指纹清单。`0_processed_新增指数列.xlsx` 没有商品 ID 或标题，只能沿用所提供的行顺序并与最终特征比对；这不是基于业务主键的可靠关联，新增数据流程应补齐标识后改为键关联。
