## 原材料提供的证据

- 五份工作簿分别保存最终九特征表、付款人数与评价标签阶段、店铺指数阶段、名称长度阶段和地区编码阶段。
- 各主数据工作表均含 28,722 条数据；含标题的阶段逐行对齐。重算付款人数与标题长度，并与保留的指数和标签合并后，九个特征逐行匹配最终表。
- 历史报告附录提供 Excel 转 CSV 思路、MySQL 建表与导入 SQL，以及部分相关性与回归探索代码。部分代码在 Word 中连成一行，不能直接等同于可运行源文件。
- 拼多多 ZIP 是第三方参考代码，未用于本项目的实际八爪鱼采集流程，也未复制到仓库。

## 对照材料修正的口径

| 参考材料中部分表述 | 工作簿核验结果与仓库处理 |
| --- | --- |
| 关键词唯一或只涉及老年人食品 | 实际有 572 个关键词，保留多搜索主题的事实 |
| 名称长度仅 28–31，先去除标点再计算 | 实际为 3–81，原字数表全部等于原文本 `len()`；按实际规则复现 |
| 回头客指数最大值 30 | 实际最大值 3000；保留原编码，不将它解释为真实复购率 |

| 已无重复记录 | 九字段有 449 条冗余行；保留来源并将出现次数写入去重结果 |
| 标签可直接推出优质评价或地区经济水平 | 缺少完整标注依据，保留标签值，缩小解释范围 |

## 数据库改进

报告中的插入后触发器会更新触发它的同一张表。本仓库采用批次与记录哈希联合主键、批量参数化写入和覆盖出现次数的 upsert 流程；无需以同表更新触发器维护重复计数。相关 SQL 语义见 [MySQL 官方 upsert 文档](https://dev.mysql.com/doc/refman/8.0/en/insert-on-duplicate.html)。

重复导入同一批次后，特征表仍为 28,273 条，出现次数合计为 28,722。该行为在独立临时 MySQL 8.0.43 实例中验证；不会把多次运行当作新增商品。
