# 简历表述与项目讲解

## 项目条目

**电商商品数据采集、清洗与 MySQL 分析**

技术：八爪鱼、Python、MySQL、SQL、Excel、Matplotlib、pytest、GitHub Actions

- 完成银发消费主题下的商品数据采集、清洗与分析，使用八爪鱼导出数据，整理 28,722 条观察记录，覆盖 572 个搜索关键词。
- 实现价格与付款人数格式转换、文本长度特征提取及数据质量核验；识别 449 条九字段冗余观察，保留来源与出现次数，形成 28,273 条去重特征记录。
- 使用 MySQL 完成结构化存储，配置类型约束、联合主键和索引；在 AI 编程辅助的工程化整理中补充参数化批量入库、重复导入校验、分组及窗口函数查询与可复现分析。

开发时间按本人真实经历填写；2026 年 10 月 29 日是本次工程整理日期。八爪鱼采集可以作为数据获取实践介绍，不表述为独立编写 Selenium / Scrapy 爬虫。

## 一分钟介绍

我做了一个电商商品数据项目，采集、清洗、MySQL 和分析都由我完成。采集使用八爪鱼，后续保留了多份 Excel 中间结果。这次把它整理成可运行仓库，核对出 28,722 条来源观察和 572 个关键词，并发现九个特征完全相同的冗余行有 449 条。数据处理会保留付款人数的加号下界含义，用内容哈希去重，再批量写入 MySQL。我还验证了同一批数据重复导入不会增加记录数，并提供了价格分布、关键词统计和相关性分析。
